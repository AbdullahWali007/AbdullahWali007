## What I'm Actually Working On

> *Not a side project. Not a tutorial clone. Something real.*

I'm building an **AI-powered video dubbing system** — the kind that takes a video in one language and outputs it in another with synced lip movement, preserved emotion, and a voice that doesn't sound like a robot reading a grocery list.

Think of it as breaking the language wall for video content, one frame at a time.

**Current status:** Deep in the weeds — model integration, audio-video sync, and figuring out how to not burn my GPU budget.
